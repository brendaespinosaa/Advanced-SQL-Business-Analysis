# Advanced SQL Business Analysis

## Project Overview

This project explores a real-world Brazilian e-commerce dataset using advanced SQL techniques to solve business problems and generate actionable insights.

The analysis focuses on customer behavior, revenue performance, retention, churn risk, seasonality, and marketplace operations. The project simulates real business analytics scenarios commonly found in data analyst, business intelligence, and product analytics roles.

Dataset source:
- Olist Brazilian E-Commerce Public Dataset

---

# Business Objectives

The project was designed to answer key business questions such as:

- Which product categories generate the highest revenue?
- Which customers generate the most value?
- What are the marketplace sales seasonality patterns?
- Which customers present churn risk?
- How strong is customer retention over time?
- Which regions outperform others in revenue generation?
- What are the most common payment behaviors?
- How does customer lifetime value vary across segments?

# Dataset Information

The project uses the Brazilian E-Commerce Public Dataset by Olist, which contains information about:

- Customers
- Orders
- Payments
- Products
- Sellers
- Freight and logistics
- Purchase timestamps

The dataset simulates a real-world marketplace environment and provides transactional data for analytical exploration.
